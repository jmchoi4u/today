# 오늘 비서 (텔레그램)

"오늘" 앱과 같은 기록을 보고, 정한 시각에 텔레그램으로 먼저 말을 거는 개인 비서예요. 집에 켜 둔 Windows 미니 PC 한 대에서 24시간 돌고, AI는 Gemini 무료 등급을 써서 **비용이 0원**이에요.

- **아침 스피드런**: 일어나면 약 → 샤워 → 아침밥 → 집 밖으로를 단계별 목표 시각에 물어보고, 출발 마감 10분 전과 마감에 알려요.
- **외부 마감**: "코테 2문제 21시"라고 보내면 오늘 핵심으로 잡고, 30분 전 · 마감 · 1시간 지남에 물어봐요. 끝나면 결과물 한 줄을 받아요.
- **예정 약**: 예정 시각에 버튼 하나로 먹었어요/건너뛰기. 1시간 지나면 한 번 더.
- **약 효과 최고 구간**: 구간이 시작될 때 "제일 어려운 거 50분?" 하고 집중 타이머를 켜요.
- **저녁**: 사장님 불편 한 줄, 걱정 시간(주차장에 적은 날만), 밤 9시 규칙과 내일 첫 결과물, 소등 30분 전 + 자기 전 약.
- **금요일 5줄**: 17시 뒤 초안을 만들어 줘요.

모든 기록은 앱과 같은 비공개 저장소에 들어가서 폰 앱에도 그대로 보여요. 무엇을 언제 물을지는 비공개 저장소의 `game.json`(루틴·매일 알림·규칙)과 앱 설정(예정 시각)을 따라요.

## 미니 PC에 설치하기 (10분)

### 준비물 3개

1. **텔레그램 봇 토큰**: 텔레그램에서 `@BotFather` 검색 → `/newbot` → 봇 이름 → 봇 아이디(끝이 `bot`) → 받은 토큰(`123456:ABC...`).
2. **Gemini API 키 (무료)**: [aistudio.google.com](https://aistudio.google.com) → Get API key → Create API key.
3. **GitHub 토큰**: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
   - Repository access: **Only select repositories** → 기록 저장소(예: `today-data`) 하나
   - Permissions → Repository permissions → **Contents: Read and write**
   - 폰 앱에 넣은 토큰과 따로 하나 더 만드는 걸 추천해요 (한쪽만 끊을 수 있게).

### 설치

1. 미니 PC에서 [이 저장소 ZIP](https://github.com/jmchoi4u/today/archive/refs/heads/main.zip)을 받아 원하는 곳(예: `C:\today`)에 압축을 풀어요.
2. `bot` 폴더의 **`install.cmd`** 를 더블클릭해요.
   - Node.js가 없으면 설치해 줘요. 설치 후 창을 닫고 `install.cmd`를 한 번 더 실행해요.
   - 준비물 3개를 붙여 넣어요 (입력하는 글자는 화면에 안 보여요).
   - 점검이 모두 `[OK]`면 자동 시작을 등록하고 비서를 켜요.
   - 로그인 없이 부팅만 해도 켜지게 하려면 `install.cmd`를 **마우스 오른쪽 → 관리자 권한으로 실행**해요.
3. 마지막에 나오는 `/start 123456` 문장을 텔레그램에서 내 봇에게 보내면 끝이에요. 그 대화에서만 움직여요.

## 쓰는 법

말로 보내도 되고, 알림에 붙은 버튼을 눌러도 돼요.

| 보내는 말 | 하는 일 |
|---|---|
| `코테 2문제 21시` / `21시까지 이력서` / `1시간 뒤 레포 정리` | 오늘 핵심 + 외부 마감 |
| `내일 10시 코테` | 내일 핵심 |
| `끝` / `끝 풀이 올림` | 가장 급한 핵심을 끝낸 걸로 + 결과물 한 줄 |
| `걱정: …` | 주차장에 넣고 걱정 시간(18시)에 같이 봐요 |
| `불편: …` | 사장님 불편 한 줄 |
| `약 먹었어` / `일어났어` / `나왔어` | 지금 해야 할 약 / 기상 / 출발 기록 |
| `오늘` | 지금 상태 |
| `/focus 50`, `/stop` | 집중 타이머 (끝나면 기록하고 뭐 했는지 물어봐요) |
| `/pause`, `/resume` | 오늘은 먼저 말 걸지 않기 / 다시 |

규칙으로 못 알아들은 말만 AI에게 물어봐요. AI도 정해진 행동(핵심 정하기, 끝내기, 기록, 주차장 등) 안에서만 답하고, 답은 한 번 더 검사해요.

## 비용과 개인정보

- **Gemini 무료 등급**은 돈이 들지 않지만, 보낸 내용이 Google의 제품 개선에 쓰일 수 있어요. 그래서 AI에게는 **항목 이름과 오늘 핵심, 그 메시지만** 보내고 약 정보(성분·곡선)나 메모 기록은 보내지 않아요.
- 더 조심하고 싶으면 `.env`에서 `LLM_PROVIDER=claude`(유료, API 데이터는 학습에 안 씀) 또는 `none`(AI 없이 규칙만)으로 바꿔요. Claude는 기본이 `claude-opus-5-5`이고, 비용을 줄이려면 `CLAUDE_MODEL=claude-haiku-5-5`로 바꿔요. Claude를 고르면 안전 분류기가 거절할 때 서버가 다른 모델로 다시 돌리는 기능(server-side fallback)이 켜져 있어요.
- 토큰과 키는 이 PC의 `bot\.env`에만 있고, 이 계정만 읽을 수 있게 해 둬요. 기록 파일(`bot\data\bot.log`)에는 토큰을 쓰지 않아요.
- 비서는 텔레그램, 기록 저장소, AI API 세 곳에만 연결돼요. PC의 다른 파일이나 명령은 건드리지 않아요.
- 처음에 `/start` 코드를 보낸 대화 하나만 주인으로 기억하고, 다른 사람의 메시지와 버튼은 무시해요.

## 관리

- **다시 설정**: `install.cmd` (Enter를 누르면 기존 값 그대로)
- **점검**: `check.cmd`
- **끄기**: `uninstall.cmd` (설정과 기록은 남겨요)
- **창을 띄워서 직접 보기**: `run.cmd`
- **업데이트**: 새 ZIP을 받아 `bot\.env`와 `bot\data`만 옮기고 `install.cmd`를 다시 실행해요.

## 문제가 생기면

- `[X] 텔레그램: 토큰이 틀렸어요` → BotFather 토큰을 다시 복사해요.
- `토큰이 이 저장소를 볼 수 없어요` → GitHub 토큰의 Repository access에 기록 저장소를 골랐는지 봐요.
- `같은 봇이 다른 곳에서도 돌고 있어요 (409)` → 다른 PC나 창에서 같은 봇을 켜 뒀는지 봐요. 하나만 켜 둬요.
- 알림 시각이 이상하면 PC의 시간대가 **(UTC+09:00) 서울**인지 봐요.
- 자세한 기록: `bot\data\bot.log`
