# 오늘 비서 (텔레그램)

"오늘" 앱과 같은 기록을 보고, 정한 시각에 텔레그램으로 먼저 말을 거는 개인 비서예요. 집에 켜 둔 Windows 미니 PC 한 대에서 24시간 돌고, AI는 Gemini 무료 등급(0원)으로 시작하고, Claude Haiku 5.5(월 몇천 원)로 바꾸면 모든 말을 AI가 앞뒤 대화와 함께 읽는 **두뇌 모드**가 켜져요.

- **아침 스피드런**: 일어나면 약 → 샤워 → 아침밥 → 집 밖으로를 단계별 목표 시각에 물어보고, 출발 마감 10분 전과 마감에 알려요.
- **외부 마감**: "코테 2문제 21시"라고 보내면 오늘 핵심으로 잡고, 30분 전 · 마감 · 1시간 지남에 물어봐요. 끝나면 결과물 한 줄을 받아요.
- **예정 약**: 예정 시각에 버튼 하나로 먹었어요/건너뛰기. 1시간 지나면 한 번 더.
- **약 효과 최고 구간**: 구간이 시작될 때 "제일 어려운 거 50분?" 하고 집중 타이머를 켜요.
- **저녁**: 사장님 불편 한 줄, 걱정 시간(주차장에 적은 날만), 밤 9시 규칙과 내일 첫 결과물, 소등 30분 전 + 자기 전 약.
- **금요일 5줄**: 17시 뒤 초안을 만들어 줘요.

- **아침 브리핑**: 일어났다고 누르면 날씨·미세먼지·옷차림, 오늘 일정, 식단, 소식 세 줄, 지금 단계를 한 번에 보내요. `브리핑`이라고 보내면 다시 줘요.
- **캘린더**: 일정 30분 전에 알려 주고, 밤 10시 뒤에 내일 일정을 한 줄로 알려 줘요 (읽기만 해요).

모든 기록은 앱과 같은 비공개 저장소에 들어가서 폰 앱에도 그대로 보여요. 무엇을 언제 물을지는 비공개 저장소의 `game.json`(루틴·매일 알림·규칙)과 앱 설정(예정 시각)을 따라요.

## 미니 PC에 설치하기 (10분)

### 준비물 3개

1. **텔레그램 봇 토큰**: 텔레그램에서 `@BotFather` 검색 → `/newbot` → 봇 이름 → 봇 아이디(끝이 `bot`) → 받은 토큰(`123456:ABC...`).
2. **Gemini API 키 (무료)**: [aistudio.google.com](https://aistudio.google.com) → Get API key → Create API key.
3. **GitHub 토큰**: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
   - Repository access: **Only select repositories** → 기록 저장소(예: `today-data`) 하나
   - Permissions → Repository permissions → **Contents: Read and write**
   - 폰 앱에 넣은 토큰과 따로 하나 더 만드는 걸 추천해요 (한쪽만 끊을 수 있게).

### 설치

1. 미니 PC에서 [이 저장소 ZIP](https://github.com/jmchoi4u/today/archive/refs/heads/main.zip)을 받아 **내 사용자 폴더 안**(예: `C:\Users\내이름\today`)에 압축을 풀어요. `C:\today`처럼 바깥에 두면 PC의 다른 계정도 기록을 볼 수 있어요.
2. `bot` 폴더의 **`install.cmd`** 를 더블클릭해요.
   - Node.js가 없으면 설치해 줘요. 설치 후 창을 닫고 `install.cmd`를 한 번 더 실행해요.
   - 준비물 3개를 붙여 넣어요 (입력하는 글자는 화면에 안 보여요).
   - 점검이 모두 `[OK]`면 자동 시작을 등록하고 비서를 켜요.
   - 로그인 없이 부팅만 해도 켜지게 하려면 `install.cmd`를 **마우스 오른쪽 → 관리자 권한으로 실행**해요.
3. 마지막에 나오는 `/start 123456` 문장을 텔레그램에서 내 봇에게 보내면 끝이에요. 그 대화에서만 움직여요.

## 캘린더 연결 (선택, 2분)

1. PC에서 [구글 캘린더](https://calendar.google.com) → 오른쪽 위 톱니바퀴 → 설정.
2. 왼쪽 "내 캘린더의 설정"에서 내 캘린더를 누르고 맨 아래로 내려가요.
3. **"iCal 형식의 비공개 주소"** 옆의 복사 버튼을 눌러요. ("공개 주소"가 아니에요.)
4. `bot\.env`를 메모장으로 열어 `CALENDAR_ICS_URL=` 뒤에 붙여 넣고 저장해요. 비서가 알아서 다시 켜져요.
5. `check.cmd`에 `[OK] 캘린더 (일정 N개 읽음)`이 나오면 끝이에요.

이 주소를 아는 사람은 내 일정을 볼 수 있어요. 어디에도 올리거나 보내지 마세요. 새로 만들고 싶으면 같은 화면의 "재설정"을 눌러요.

## 아침 브리핑 설정

무엇을 보여 줄지는 비공개 저장소 `game.json`의 `brief`로 정해요.

```json
"brief": {
  "loc": { "lat": 37.5, "lon": 127.0 },
  "news": { "keywords": ["관심 키워드"], "max": 3, "hours": 48 },
  "meals": { "weekday": ["아침 ...", "점심 ..."], "weekend": ["..."] }
}
```

- `loc`가 있으면 날씨·미세먼지·옷차림을 넣어요. 위치는 소수 첫째 자리(약 10km)까지만 Open-Meteo에 보내요.
- `news.keywords`가 있으면 Google 뉴스에서 키워드마다 최근 소식을 받아 세 줄까지 보여 줘요. 키워드만 보내요.
- `meals`는 평일·주말에 보여 줄 끼니 줄이에요.
- 캘린더 내용과 기록은 어디에도 보내지 않아요.

## 쓰는 법

말로 보내도 되고, 알림에 붙은 버튼을 눌러도 돼요.

| 보내는 말 | 하는 일 |
|---|---|
| `코테 2문제 21시` / `21시까지 이력서` / `1시간 뒤 레포 정리` | 오늘 핵심 + 외부 마감 |
| `내일 10시 코테` | 내일 핵심 |
| `끝` / `끝 풀이 올림` | 가장 급한 핵심을 끝낸 걸로 + 결과물 한 줄 |
| `걱정: …` | 주차장에 넣고 걱정 시간(18시)에 같이 봐요 |
| `불편: …` | 사장님 불편 한 줄 |
| `약 먹었어` / `일어났어` / `나왔어` | 지금 해야 할 약 / 기상 / 출발 기록 |
| `3시 10분에 약 먹었어` / `10시 반에 일어났어` | 지난 일은 그 시각으로 (이미 남긴 기록이면 시각을 고쳐요) |
| `되돌려` | 방금 비서가 남긴 기록을 취소 (6시간 안, 세 번까지) |
| `기억해: 발표 전날은 알림 줄여 줘` / `기억` / `잊어 m3` | 오래 기억할 사실 넣기 / 목록 보기 / 지우기 (두뇌 모드) |
| `오늘` | 지금 상태 |
| `브리핑` | 아침 브리핑 다시 보기 |
| `/focus 50`, `/stop` | 집중 타이머 (끝나면 기록하고 뭐 했는지 물어봐요) |
| `/pause`, `/resume` | 오늘은 먼저 말 걸지 않기 / 다시 (꺼 둔 아침 루틴 알림도 다시 켜요) |
| `/update` | 새 버전이 있으면 바로 받기 |

AI는 두 가지로 써요. 어느 쪽이든 AI는 정해진 행동(핵심 정하기, 끝내기, 기록, 약, 기상, 되돌리기 등) 안에서만 답하고, 답은 한 번 더 검사해요.

- **두뇌 모드 (Claude):** 모든 말을 AI가 먼저 읽어요. 오늘 상태(기상, 루틴, 핵심, 약을 먹었는지, 일정)와 최근 12시간 대화 20개를 같이 봐서 "지금 일어난 건 아니고" 같은 말도 앞뒤로 알아들어요. AI가 안 되면 규칙으로 처리해요.
- **기본 (Gemini 무료):** 규칙으로 먼저 풀고, 못 알아들은 말만 AI에게 물어봐요.
- 규칙은 확실할 때만 기록해요. "약 안 챙겼어", "알람 7시인데 9시에 깼어", "동생이 7시에 깼어" 같은 말은 기록하지 않아요.
- **기억 3층 (두뇌 모드):** 비공개 저장소의 `brain/` 폴더에 글로 남겨요.
  - `profile.md`: 내가 직접 쓰는 "나는 이런 사람, 이렇게 대해 줘". 비서는 읽기만 해요.
  - `memory.md`: 오래 갈 사실 목록(최대 60줄). `기억해: …`로 넣어요.
  - `log/날짜.md`: 그날 일지. 하루가 바뀌면(새벽 4시) 어제 대화로 일지를 쓰고, 기억을 고칠 제안을 최대 3개 받아 검사를 통과한 것만 반영해요. 메시지는 보내지 않아요. 어제 내가 한 말이 없으면 AI를 부르지 않아요.
  - 글 파일이라 직접 고쳐도 되고, GitHub 기록으로 되돌릴 수 있어요.
- **조용한 점검:** 같은 종류의 알림에 사흘 연속 반응이 없으면 그 종류는 3일 쉬어요 (낮에 한 번 알리고 "다시 받기" 버튼을 줘요). 36시간 동안 아무 반응이 없고 그동안 알림을 셋 넘게 보냈으면 약·마감·일정·출발 마감·첫 기상 확인만 남기고 한 번만 가볍게 물어요. 반응은 텔레그램에서 말하거나 버튼을 누르는 것, 폰 앱에서 기록하는 것 모두예요. 약 알림(아침 루틴의 약 단계 포함), 내가 정한 마감, 캘린더, 집중 타이머 끝은 줄이지 않아요. `/resume`은 쉬던 알림을 모두 다시 켜요.
- "죽고 싶다" 같은 위기 신호는 AI에게 보내지 않고 정해진 글(109, 119)로 답하고, 그날 먼저 말 걸기를 멈춰요.

## 비용과 개인정보

- **Gemini 무료 등급**은 돈이 들지 않지만, 보낸 내용이 Google의 제품 개선에 쓰일 수 있어요. 그래서 AI에게는 **항목 이름과 오늘 핵심, 그 메시지만** 보내고 약 정보(성분·곡선)나 메모 기록은 보내지 않아요. 메시지와 핵심 글 속의 약 이름도 이름표로 가려서 보내요.
- **Claude (두뇌 모드)**는 유료예요. Anthropic 약관상 API로 보낸 내용은 학습에 쓰지 않아요. `CLAUDE_MODEL=claude-haiku-5-5` 기준으로 하루 메시지 15~40개면 한 달 약 ₩2천~3천, 하루 한도(150번)를 다 써도 ₩1만 안팎이에요. `claude-opus-5-5`로 바꾸면 약 40배예요. 콘솔에서 월 한도를 꼭 걸어 두세요.
- 두뇌 모드에서 AI에게 가는 것: 오늘 상태, 최근 12시간 대화 20개, 새 메시지, 기억(`brain/profile.md`, `memory.md`, 어제 일지). 밤 정리 때는 그날 대화(8천 자까지)와 하루 끝의 상태. **약 이름·별명·용량은 "[아침 약]" 같은 이름표로 바꿔서** 보내요 (설정의 약 항목 이름, 연결된 약 이름, `aliases`). 예전에 가렸던 이름과 약 정보에 등록된 약 이름도 계속 가려요. 설정에 없는 약 이름(오타, 영문 이름 포함)을 직접 쓰면 그대로 가니, 자주 쓰는 이름은 비공개 설정(`config.json`)의 약 항목에 `aliases`로 넣어 두세요.
- AI를 아예 안 쓰려면 `LLM_PROVIDER=none` (규칙만). 유료 Gemini에서 두뇌 모드를 쓰려면 `LLM_FULL_CONTEXT=1`.
- 최근 대화는 이 PC의 `bot\data\state.json`에만 40개까지 남아요.
- 토큰과 키는 이 PC의 `bot\.env`에만 있고 (기록 파일 `data\store.json`에는 토큰을 넣지 않아요), 이 계정만 읽을 수 있게 해 둬요. 기록 파일(`bot\data\bot.log`)에는 토큰을 쓰지 않아요.
- 비서는 텔레그램, 기록 저장소, AI API에 연결돼요. 브리핑을 켜면 날씨(Open-Meteo), Google 뉴스, 내 캘린더 주소에서 읽어 오기만 해요. PC의 다른 파일이나 명령은 건드리지 않아요.
- 처음에 `/start` 코드를 보낸 대화 하나만 주인으로 기억하고, 다른 사람의 메시지와 버튼은 무시해요.

## 관리

- **다시 설정**: `install.cmd` (Enter를 누르면 기존 값 그대로)
- **점검**: `check.cmd`
- **끄기**: `uninstall.cmd` (설정과 기록은 남겨요)
- **창을 띄워서 직접 보기**: `run.cmd`
- **업데이트**: 자동이에요. 10분마다 이 저장소에 새 버전이 있는지 보고, 있으면 받아서 다시 켜져요. 텔레그램에 `/update`라고 보내면 바로 확인해요. 바뀌면 "새 버전으로 다시 켜졌어요"라고 알려 줘요.
  - 새 버전은 문법 검사와 켜 보기를 통과해야 적용돼요. 적용 뒤 바로 죽기를 세 번 하면 이전 버전으로 되돌려요.
  - `.env`와 `data`는 건드리지 않아요.
  - 끄려면 `.env`에 `AUTO_UPDATE=off` (그래도 `/update`는 돼요).
  - 자동 업데이트는 이 저장소에 올라온 코드를 이 PC가 그대로 실행한다는 뜻이에요. 저장소를 포크해서 쓰면 `.env`에 `UPDATE_REPO=계정/저장소`를 넣어요.
- **죽으면 다시 켜기**: 감시 프로그램(`supervisor.mjs`)이 비서를 지켜보다가 꺼지면 다시 켜요.

## 문제가 생기면

- `[X] 텔레그램: 토큰이 틀렸어요` → BotFather 토큰을 다시 복사해요.
- `토큰이 이 저장소를 볼 수 없어요` → GitHub 토큰의 Repository access에 기록 저장소를 골랐는지 봐요.
- `같은 봇이 다른 곳에서도 돌고 있어요 (409)` → 다른 PC나 창에서 같은 봇을 켜 뒀는지 봐요. 하나만 켜 둬요.
- 알림 시각이 이상하면 PC의 시간대가 **(UTC+09:00) 서울**인지 봐요.
- 자세한 기록: `bot\data\bot.log`

## 개발

```bash
node --test bot/test/*.test.mjs
```

앱의 `js/core.js`, `js/game.js`, `js/pk.js`, `js/store.js`, `js/sync.js`를 그대로 가져다 써서, 기록이 폰과 같은 규칙으로 합쳐져요.
