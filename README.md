# 오늘 — 하루 퀘스트

약, 루틴, 식사, 집중을 한 번 탭으로 기록하는 하루 추적기입니다. 폰 크롬에서 열고 홈 화면에 추가해 앱처럼 씁니다.

## 무엇을 하나

- **원탭 기록**: 타일을 누르면 체크와 시각이 남습니다. 길게 누르면 시각 수정과 건너뛰기.
- **기상 기준 하루**: 시계가 아니라 일어난 시각부터 기상 후 → 낮 → 저녁 → 자기 전 순서로 흐릅니다. 못 한 항목은 다음 시간대로 넘어옵니다.
- **코치**: 지금 상태를 보고 다음에 할 한 가지를 권합니다 (규칙 기반).
- **EXP와 시즌**: 체크하면 EXP가 쌓이고, 2주 단위 시즌으로 결과를 끊어서 봅니다.
- **흐름 그래프**: 약·식사·음료·집중·컨디션을 시간축에 그립니다.
- **누적 목표, D-day, 보고하기**: 닫힌 범위와 고정된 날짜를 화면에 걸고, 하루 요약을 사람에게 보냅니다.
- **약 탭**: 비공개 저장소의 `meds.json`에 적은 약 정보(허가사항 수치에 맞춘 방출 모델)로 복용 시각에 맞춘 효과 곡선, 효과·최고 구간, 잠과의 거리, 기록한 집중도로 본 개인 피크를 보여줍니다. 약 이름과 설명은 이 공개 저장소에 없습니다.

## 기록은 어디에 있나

- 이 저장소에는 앱 코드만 있습니다. 기록은 들어 있지 않습니다.
- 기록은 쓰는 기기의 브라우저에 저장됩니다.
- 설정에서 본인의 **비공개** GitHub 저장소를 연결하면 `config.json`과 `days/연도/날짜.json`으로 동기화됩니다. 공개 저장소는 연결되지 않습니다.
- 토큰은 그 기기에만 저장되고 어디로도 전송되지 않습니다 (GitHub API 호출 제외).
